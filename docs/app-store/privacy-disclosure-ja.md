# Appのプライバシー回答メモ

実装済みのGoogle Mobile Ads SDKのPrivacy Manifestを基準にした入力メモです。App Store Connect上の既存回答は、次回更新時に次の内容と照合します。

| データタイプ | 目的 | ユーザーへの関連付け | トラッキング |
| --- | --- | --- | --- |
| おおよその位置情報 | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | はい | いいえ |
| デバイスID | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | はい | SDK設定と同意状態に応じて確認 |
| 製品の操作 | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | はい | いいえ |
| 広告データ | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | はい | いいえ |
| クラッシュデータ | アナリティクス | いいえ | いいえ |
| パフォーマンスデータ | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | いいえ | いいえ |
| その他の診断データ | サードパーティ広告、デベロッパの広告またはマーケティング、アナリティクス | いいえ | いいえ |

入力したタスク、メモ、集中記録、設定は端末内にのみ保存されるため、開発者によるユーザーコンテンツの収集には含めません。
